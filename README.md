# JogoPMO
Jogo gerado com Google AI Studio, para atividade do Projeto Multidisciplinar Online.   

Script inicial:

Atue como um desenvolvedor de jogos web sênior e especialista em HTML5/JavaScript.
Objetivo: Crie um jogo completo estilo "Quiz de Viagem no Tempo" em um ÚNICO ARQUIVO contendo HTML, CSS e JavaScript integrados.
História e Enredo:
O jogador controla um Viajante do Tempo gótico que viaja através das eras. Em cada etapa, ele precisa analisar as pistas do ambiente e descobrir em qual momento da história desembarcou com sua máquina do tempo.
Mecânicas de Jogo Obrigatórias:
Estrutura de Quiz: Cada fase deve apresentar um texto descritivo com pistas da época e EXATAMENTE 3 alternativas de resposta em formato de botões.
Sistema de 2 Chances: O jogador tem EXATAMENTE 2 chances para acertar a resposta em cada pergunta/fase:
1º Erro: Perde 1 tentativa, exibe uma dica extra na tela e o jogador pode tentar responder novamente entre as opções restantes.
2º Erro: Ativa imediatamente a tela de Game Over.
Placar e Progresso: Exiba o indicador de fase atual (ex: "Época 1 de 5"), o número de tentativas restantes na fase e a pontuação total acumulada.
Fluxo de Telas:
Tela Inicial: Título "ChronoQuiz: As Eras Sombrias", breve introdução do enredo e botão "Iniciar Viagem".
Tela do Jogo: Área principal com o texto do enigma, botões com as 3 alternativas e painel de status.
Tela de Game Over: Mensagem de derrota ao esgotar as chances, pontuação alcançada e botão "Tentar Novamente".
Tela de Vitória: Mensagem ao concluir todas as épocas com sucesso e botão "Jogar Novamente".
Design e Estilo Visual (Estética Gótica):
Paleta de Cores Estrita: Fundo em preto profundo/grafite escuro, elementos de destaque/botões em vinho/burgundy e detalhes/bordas/textos em verde musgo.
Atmosfera: Visual sombrio, elegante e medieval/gótico, utilizando sombras internas, bordas estilizadas e tipografia legível que combine com o tema.
Responsividade: Layout centralizado na tela que funcione perfeitamente tanto no computador quanto no celular.
Requisitos Técnicos:
Código Único: Todo o HTML, CSS e JavaScript deve estar no mesmo arquivo (use as tags <style> e <script> internamente).
Sem Dependências Externas: Utilize apenas JavaScript puro (Vanilla JS) e CSS puro, sem frameworks ou bibliotecas externas.
Comentários: Inclua comentários breves no código JavaScript para facilitar a leitura.
Saída Esperada:
Forneça APENAS o bloco de código estritamente completo e pronto para ser copiado, sem cortes, resumos ou partes omitidas.

Após rodar o código inicial, pedi que adicionasse uma tela de transição após o acerto e criasse uma atmosfera de acordo com o período histórico da fase acertada. Pedi que melhorasse a moldura e adaptasse de acordo com o tamanho do texto. 
No código alterei o tempo de exibição da tela de transição entre as fases.
